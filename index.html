Petrihos Lever Index (PLI)

Deterministic macroeconomic adjudication for Statecraft Simulations Group / Fractured Order. Each economic action becomes an attributable quarterly path against an IMF-anchored baseline—rule-based, fully traceable, and signed by an SME.

Directional, not predictive — the chart is the adjudication; the SME signs it.

From matrix cell to quarterly path

PLI turns a coded action into an impulse path on each indicator. The post-action series is the baseline plus that impulse. Green fill = favorable divergence; red = unfavorable.

Pi(q) = Bi(q) + Δi(q)
Δi(q) = sign(d) · value(class_eff) · w(q; startq, ramp, plateau, decay)
  • Bi(q) — U.S. baseline for indicator i at quarter q (IMF Article IV anchored)
  • Δi(q) — action impulse path
  • w(·) — normalized quarterly weight profile
  • q ∈ {2026Q1 … 2034Q4}; t0 — submission month → calendar quarter

One indicator — quarterly path

Tensor flow

PLI stores every impulse in a 3-way tensor over actions, indicators, and quarters. One highlighted cell is a single action’s effect on one indicator in one quarter.

Cell definition
T[a, i, q] = Δi,a(q)

Each coded action writes an impulse into the tensor at action a, indicator i, quarter q.

Stack across actions
Tstacked[i, q] = Σa T[a, i, q]

Default aggregation is uncapped summation—plenary path equals the sum of every action’s impulse.

Observed path
Pi(q) = Bi(q) + Tstacked[i, q]

Post-action series = IMF-anchored baseline + stacked impulses. Every point traces to a codebook rule and an SME sign-off.

PLI output: attributable quarterly trend lines

Five indicators: real GDP growth, PCE inflation, unemployment, trade volume, and fixed investment. Baselines are anchored to IMF Article IV projections and corroborated with public outlooks (CBO, Fed, WTO, OECD). Use the buttons to switch channels for the same worked example.
