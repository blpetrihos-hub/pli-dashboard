Petrihos Lever Index (PLI)

Deterministic macroeconomic adjudication for Statecraft Simulations Group / Fractured Order. Each economic action becomes an attributable quarterly path against an IMF-anchored baseline—rule-based, fully traceable, and signed by an SME.

Directional, not predictive — the chart is the adjudication; the SME signs it.

From matrix cell to quarterly path

PLI turns a coded action into an impulse path on each indicator. The post-action series is the baseline plus that impulse.

Pi(q) = Bi(q) + Δi(q)
Δi(q) = sign(d) · value(class_eff) · w(q; startq, ramp, plateau, decay)
  • Bi(q) — U.S. baseline for indicator i at quarter q (IMF Article IV anchored)
  • Δi(q) — action impulse path
  • w(·) — normalized quarterly weight profile
  • q ∈ {2026Q1 … 2034Q4}; t0 — submission month → calendar quarter

One indicator — quarterly path

Tensor flow

Each action contributes one impulse slice. Stacking across actions (default: uncapped) gives the plenary path:

T_stacked[i, q] = Σa T[a, i, q]

PLI implements T with codebook tables and deterministic scoring— every point traces back to a rule and an SME decision.

PLI output: attributable quarterly trend lines

Five indicators: real GDP growth, PCE inflation, unemployment, trade volume, and fixed investment. Baselines are anchored to IMF Article IV projections and corroborated with public outlooks (CBO, Fed, WTO, OECD).
